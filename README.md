# 🔐 Cyber Toolkit

A beginner Python cybersecurity project that simulates a simple login and registration system using file-based storage.

## 🧠 About the Project

This project was built to practice basic cybersecurity and Python programming concepts such as authentication, data storage, and user input handling.

It acts as a simple login system where users can:
- Register an account
- Log in with existing credentials

User data is stored locally in a JSON file.

---

## ⚙️ Features

- User registration system 🧾  
- Login authentication 🔐  
- Data saved using JSON file storage 📁  
- Simple terminal-based interface 💻  

---
